# 我的歌单 · 自动连播

一个用 **B 站当音源**的桌面音乐播放器。Electron 套壳，搜歌、加歌、歌单管理、自动连播全在本地完成，不依赖任何第三方音乐平台。

> 不用充会员，不用听广告——因为压根没走音乐平台。代价是：你在听 B 站视频的声音。

## 功能

- **搜歌**：直接调 B 站搜索接口，按关键词找视频，选一个加进歌单
- **加歌**：粘贴 BV 号或视频链接，自动抓标题、UP 主、时长、播放量
- **歌单管理**：增、删、排序、搜索过滤，可导入/导出歌单 JSON，可一键恢复默认
- **自动连播**：一首放完自动下一首，打开即播（已放开 autoplay 限制）
- **播放控制**：播放/暂停、拖动进度条跳转，进度条实时同步真实播放状态
- **MV 模式**：想看的视频可以直接开画面，不只是听声音
- **本地存储**：歌单存在 localStorage（`myList_v1`），关掉再开还在

## 项目结构

```

music_icon.ico             # 应用图标
test_search.js             # 自动测试：搜索 + 添加
test_migrate.js            # 自动测试：歌单数据版本迁移
test_page.js / test_web.js # 自动测试：页面加载 / 网页模式
```

## 实现说明

- **为什么要 Electron 而不是纯网页**：浏览器的跨域策略不允许直接请求 B 站接口，也不允许跨 iframe 操作播放器。主进程绕开了这两道限制——`main.js` 里 `runInPlayer()` 会遍历所有子 frame，找到 bilibili 那一帧再执行 JS 控制 `<video>`。
- **搜索会不会被风控**：搜索接口需要带 `buvid3` cookie，代码里塞了一个固定的假值能过。失效了就在 `biliGet()` 里换一个。
- **数据迁移**：歌单结构改过版本（现场版 → 录音室版），`test_migrate.js` 就是验证老数据能不能平滑升上来的。
